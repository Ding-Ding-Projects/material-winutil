Guides

Build and use the verified baseline

The installer is unsigned and the release feed is mutable.

1

Build the runnable application

build.bat /s

The root path bootstraps required tools and builds the runnable application.

2

Build the installer

build-installer.bat /s

The installer path creates unsigned Squirrel.Windows artifacts and reports SHA-256.

3

Use exact package records

Search by name or identifier, review the selected count, and run only a supported exact operation.

4

Read the real result

A failed process stays failed. The interface does not infer success from silence.
